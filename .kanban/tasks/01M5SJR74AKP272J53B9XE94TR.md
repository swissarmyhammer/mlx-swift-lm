## What
Schema output (`runSchemaGeneration`) and required tool calls (`runRequiredToolTurn`) run `GuidedGenerationLoop.run` (Libraries/MLXGuidedGeneration/GuidedGenerationLoop.swift ~112-563). This loop is separate from `generateLoopTask`: it uses a new KV cache each time and no prompt cache (`carriesNoCache`, Libraries/MLXFoundationModels/MLXLanguageModel.swift ~1666, ~2248), applies an xgrammar bitmask plus closing, whitespace, and reserve biases that change with the position (`applyMaskAndSample` ~531-563, biases ~255-275, MLXLanguageModel.swift ~1708-1724), and always takes argmax. Thus guided output is greedy.

The matcher is stateful for each token: `computeMask()` (Libraries/MLXGuidedGeneration/XGrammarBridge.swift ~515) reads the current state, and `commitToken(_:fastForward:)` (~560-665) accepts a token and its forced jump-forward tokens. `rollback(n)` (~698-707) exists, and `n` must include the fast-forward acceptances. Forced tokens are fed to the model one at a time (GuidedGenerationLoop.swift ~356-422); a comment (~387-393) reports an MLX causal SDPA bug with T_q > 1 on a populated cache for Gemma 3.

- [ ] Prefill: the loop makes a new cache, so prefill the target with the per-chunk hidden-row hook and feed a new drafter state over the full prompt (no reuse in this loop).
- [ ] Draft with the MTP drafter: for each draft position, take the argmax of the drafter logits after the mask AND the position biases of that position, `commitToken` it, and get the next mask and biases. Record the number of matcher acceptances (draft + fast-forward) for each draft.
- [ ] Verify with one target forward pass, apply the mask and biases of each position to the target logits, and accept while the target result equals the draft. On a rejection, `rollback` the matcher by the recorded count, commit the target token, and rewind the main cache with the multi-token rewind.
- [ ] Put the forced fast-forward tokens into the same verify batch only for targets where a test proves T_q > 1 on a populated cache is correct (Qwen35); keep the one-token feed for other targets. Use the MTP path only when the target has a drafter.
