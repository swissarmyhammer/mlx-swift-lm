## Why
A decode step submits several hundred small kernels. The command-buffer size (MLX's ops per buffer, set by the environment or the device default) changes how many commits and waits a step pays. Checking it costs nothing.

## What
- Run inklingbench.sh at several ops-per-buffer settings, for example 20, 50, 100 and 200, against the default.
- If one setting wins beyond the noise, find out whether it can be set per model, or whether it only belongs in the documentation for Inkling users.

## Acceptance
- [ ] The card records a table of decode ms/tok and prefill tok/s per setting.
- [ ] Any library change passes inklingcheck.sh. #inkling-perf
