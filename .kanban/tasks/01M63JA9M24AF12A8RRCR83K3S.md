title: 'FoundationModels: replay the reasoning of a turn that stopped inside its reasoning for protocols with replaysUnclosedReasoningIntoHistory (DeepSeek-V4)'

Found in ^k2zn64x. `MLXLanguageModel.Executor.historyMessages` replays reasoning only when `ReasoningConfig.replaysReasoningIntoHistory` is set (Qwen). `ChatSession.ReasoningHistory` also honors `replaysUnclosedReasoningIntoHistory` (DeepSeek-V4, card ^mf1mwaw): a turn that stopped inside the block its prompt opened is recorded as `.assistant("", reasoning: text)`. In FoundationModels such a turn is an empty response entry beside a reasoning entry, and the reasoning is dropped, thus the follow-up render omits the turn and a hybrid model restores to the checkpoint. ^k2zn64x made `TranscriptConverter.mlxMessages(replayReasoning: true)` keep a reasoning-only turn; this card applies that to the unclosed-only protocols.

- [x] Give `TranscriptConverter.mlxMessages` a replay mode for unclosed reasoning only: replay the reasoning of a turn whose response is empty, drop it otherwise
- [x] Wire `historyMessages` to `replaysUnclosedReasoningIntoHistory`
- [x] Unit tests in a new file; DSV4 real-model follow-up measurement if a local model exists
