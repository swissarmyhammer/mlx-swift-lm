## What

Path gap, not a line gap. The lines are covered by other tests, but no unit test sends a real Qwen cache shape through the executor file.

Files and measured coverage:
- `Libraries/MLXFoundationModels/ExecutorPromptCacheFile.swift` `prepare(_:key:)` 86-99 and `read(from:key:templates:)` 134-158: 100%. The only fixtures are `KVCacheSimple`, an unwrapped `RotatingKVCache` and a `MambaCache` with ramp values, and a model state under the test key `test.ropeDeltas` (`Tests/MLXFoundationModelsTests/ExecutorPromptCacheFileTests.swift:139-170`).
- `Libraries/MLXVLM/Models/Qwen35.swift` `Qwen35.newCache(parameters:)` 1108-1110: 3/3; `Qwen35.prepare(_:cache:state:prefill:)` 1231-1279: 49/49.
- `Libraries/MLXVLM/Models/Qwen3VL.swift` `Qwen3VL.prepare(_:cache:state:prefill:)` 1812-1854: 43/43.

The Qwen tests that use a file (`Tests/MLXLMTests/Qwen35ContinuationTests.swift:178-268`, `Tests/MLXLMTests/Qwen3VLContinuationTests.swift:294-338`) use `savePromptCache` and `loadPromptCacheSnapshot(url:)`, which builds new caches from the class names. The executor uses `loadPromptCacheSnapshot(url:into:)` with `model.newCache(parameters:)` templates, the offset check of `ExecutorPromptCacheFile.read` and the token ledgers. No test runs a Qwen3.5 hybrid (`MambaCache` + `KVCacheSimple`) or a Qwen3-VL cache through that path.

What to test:
- Make the tiny Qwen3.5 model of `Qwen35ContinuationTests.makeTinyModel()` (4 layers, `full_attention_interval` 2) and the tiny Qwen3-VL model of `Qwen3VLContinuationTests`.
- Prefill a text prompt into `model.newCache(parameters: nil)`. Make an `ExecutorPromptCacheEntry` with the caches, the ledger, a render ledger and the `LMOutput.State` of the prefill.
- `ExecutorPromptCacheFile.prepare`, `write`, then `read(from:key:templates: model.newCache(parameters: nil))`.
- Expect: the restored classes are the classes of `newCache` (the restore writes into the templates), every offset equals the ledger length, `tokens` and `renderTokens` are equal, and `state?[qwen35.ropeDeltas]` (or `qwen35vl.ropeDeltas`) equals the saved array.
- Continue with the next text tokens on the restored entry and on the live caches. The last logits must agree within 1e-6. The logits must also agree within 1e-3 with a cold prefill of the whole prompt.
- Negative control: read the file, drop the state, and expect `ContinuationStateError.missingState` from `prepare`.
