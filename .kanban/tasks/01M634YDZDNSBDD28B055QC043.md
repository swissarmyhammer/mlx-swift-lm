## What
Found while doing ^smn05mj. `IntegrationTesting/IntegrationTestingTests/MTPGreedyVerificationIntegrationTests.swift` `tokenAndCacheParity()` ends with `guard ProcessInfo.processInfo.environment["MTP_GREEDY_BENCHMARK"] == "1" else { return }` and then times five 128-token runs of the sequential and the batched verification paths on Qwen3.5-4B-4bit (`[MTPGREEDYE2E]` line). The test-partitioning rule forbids an environment variable that decides whether a test (or a part of it) runs; the optional-guard rule forbids a `guard ... return` in a test. ^smn05mj moved the unit-bundle micro-benchmark to `MTPGreedyVerificationBenchmarkTests` (IntegrationTesting) and deleted the switch there; this is the last reader of `MTP_GREEDY_BENCHMARK`.

- [ ] Split the end-to-end timing into its own `@Test` (gated only by the model files being local, like `tokenAndCacheParity`), with no environment switch, or fold it into GenerationBenchmarkTests if that already covers it.
- [ ] No source file reads `MTP_GREEDY_BENCHMARK`.
